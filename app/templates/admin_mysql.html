Configuration Instructions

To enable MySQL database access for the AI chatbot, configure your database connection in the .env file:

Option 1: Using DATABASE_URL (recommended for production)
DATABASE_URL=mysql+mysqlconnector://username:password@host:3306/database_name
Option 2: Using individual environment variables
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_USER=your_username
MYSQL_PASSWORD=your_password
MYSQL_DATABASE=your_database_name
Note: After updating the configuration, restart the Flask application for changes to take effect.
